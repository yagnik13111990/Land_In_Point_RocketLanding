Rocket Lander is a 2D physics-based game where you control a rocket capable of flying and rotating in its facing direction.
The rocket uses realistic physics to simulate thrust, gravity, and momentum.
Your mission: avoid incoming obstacles, stabilize flight, and land safely on the target pad.

Each movement matters — over-rotate or thrust too hard, and the rocket will spin out of control!

 Core Features:

Fully physics-driven rocket movement

Directional thrust control (fly where you face)

Obstacle avoidance mechanics

Smooth landing detection and scoring system

Realistic gravity and inertia simulation

 Tech Highlights:

Built with Unity 2D physics engine

Rigidbody-based movement and torque control
